# [M1][P0] Implement PostgreSQL, SQLAlchemy async, Alembic, and Redis infrastructure

## Objective

Add async SQLAlchemy engine/session dependency, Alembic migration environment, Redis lifecycle, health checks, Docker Compose dependencies, and integration fixtures. Each concurrent task owns its AsyncSession. Migrations apply to a fresh DB and run in CI. Redis is ephemeral coordination only; PostgreSQL remains durable source of truth.
