# [M5][P1] Implement usage ledger, pricing versions, and quota accounting

## Objective

Add durable usage ledger, provider-reported/estimated/unavailable states, versioned pricing, Decimal/Numeric money calculations, quota reservation and reconciliation. Accounting is idempotent; unknown costs are never invented; failed/cancelled/partial generations have explicit rules; quotas cannot be overspent under concurrent requests.
