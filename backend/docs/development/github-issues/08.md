# [M4][P0] Build generation lifecycle, SSE streaming, cancellation, and idempotency

## Objective

Persist user message and pending generation before provider I/O; implement POST SSE protocol, deltas, terminal events, heartbeats, anti-buffering headers, cancellation/disconnect, partial response persistence, recovery, and idempotency keys. No DB transaction remains open during provider I/O. Never switch providers after visible output. Test duplicate requests, partial output, disconnect, timeout, malformed chunks, and cleanup paths.
