# [M2][P0] Implement secure email authentication and session lifecycle

## Objective

Implement users, normalized unique email, Argon2id, short-lived access tokens, opaque hashed refresh tokens, rotation, reuse detection, expiry, revocation, and login/registration limits. Test plaintext secrets are never persisted, old refresh tokens stop working, logout revokes, and auth errors do not disclose account existence. OAuth/OIDC follows later.
